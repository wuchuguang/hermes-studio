# 触控与动效规范

`design-mobile-apps` 的实施细则，涉及具体数值时按本文执行。

## 触控目标

| 项目 | 数值 |
|---|---|
| 最小触控目标 | 44×44px（可视图标可 24px，但点击热区补足 44px） |
| 相邻可点目标间距 | ≥ 8px |
| 拇指热区 | 屏幕下 2/3，核心操作优先放底部 1/3 |
| 列表项高度 | ≥ 48px（含图标行 ≥ 56px） |
| 底部标签栏高度 | ≥ 49px + 底部安全区 |

## 手势与交互习惯

- iOS：边缘右滑返回、下拉刷新、列表左滑出操作（默认删除/更多）。
- Android：系统返回键走历史栈，顶部下拉刷新，长按出上下文菜单。
- 弹层：底部弹层带拖拽把手（36×5px 圆角条），下拉或点遮罩关闭。
- 输入：键盘弹起时聚焦字段滚动到可视区；提交失败定位到第一个错误字段且不丢输入。

## 动效时长与缓动

| 场景 | 时长 | 缓动 |
|---|---|---|
| 按压反馈 | 80–120ms | ease-out |
| 开关、选中切换 | 150–200ms | ease-in-out |
| 页面/分段过渡 | 200–300ms | 标准缓动 |
| 弹层进出 | 250–350ms | 进入 ease-out / 退出 ease-in |
| 骨架屏→内容 | 150ms 淡入 | ease-out |

- 超过 400ms 的动画必须有明确功能目的（教学、引导），否则删除。
- 位移过渡遵循加速进入、减速退出；同屏同时运动元素不超过 2 个。
- `prefers-reduced-motion: reduce` 时关闭位移与缩放，保留透明度过渡。

## 三态与反馈

- 可交互元素三态齐全：默认态、按压态（透明度 0.6 或缩放 0.97）、禁用态（透明度 0.35 + 不可点）。
- 异步操作：按钮加载态防重复提交；成功有轻反馈（不用阻塞式弹窗）；失败可重试。
- 破坏性操作二次确认放底部确认弹层，主按钮用危险色，不与主操作同屏并列。
