# 视觉系统令牌

`design-mobile-apps` 的视觉基础数值，与 `vue-bun-pwa` 的主题变量体系对接。

## 字号阶梯（5 级）

| 级别 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| 大标题 | 34/41 | 700 | 页面主标题、空状态数字 |
| 标题 | 22/28 | 600 | 分组标题、卡片主信息 |
| 正文强调 | 17/24 | 600 | 列表标题、按钮文字 |
| 正文 | 15/22 | 400 | 常规内容、表单 |
| 辅助 | 13/18 | 400 | 说明、标签、时间戳 |

- 全角正文一行 30–40 字符；行高正文 1.5，标题 1.2。
- 数字列、金额用 `font-variant-numeric: tabular-nums`。

## 间距与圆角

- 间距阶梯：4 / 8 / 12 / 16 / 24 / 32（4px 基数）。
- 页面左右边距统一 16px；卡片内边距 16px；分组间距 24px。
- 圆角两档：卡片 16px、控件（按钮/输入框）10px；标签胶囊用 999px。
- 分隔线 0.5px `hairline`（深浅主题各配色），优先用分组留白替代满屏分隔线。

## 颜色语义

| 令牌 | 用途 |
|---|---|
| `--color-primary` | 主操作、选中态 |
| `--color-primary-active` | 主色按压态（加深 8%） |
| `--color-success` / `--color-warning` / `--color-danger` | 语义反馈 |
| `--color-text-1` / `2` / `3` | 主文本 / 次文本 / 占位与禁用 |
| `--color-bg-1` / `2` / `3` | 页面背景 / 卡片背景 / 分组内背景 |
| `--color-border` | 边框、分隔线 |

- 深浅主题各自成套，禁止只做一套再反色。
- 文本对比度：正文 ≥ 4.5:1，大字号 ≥ 3:1。
- 危险操作的主按钮必须用 `--color-danger`，不与常规主按钮混用。

## 图标

- 线性或填充风格全局二选一；尺寸对齐字号阶梯：16 / 20 / 24。
- 图标颜色跟随文字颜色令牌，不单独定义图标色板。
- 纯图标按钮必须有 `aria-label`，热区补足 44px。

## 避免模板化处理

- 标题单词变色、全大写标签、内容上方多余小标签、整页同质卡片墙、装饰性渐变横幅——一律不做。
- 视觉焦点每屏一个：靠字号 + 字重 + 留白拉开，不靠颜色叠加。
